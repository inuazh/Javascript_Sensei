# Публикация в RuStore

## 1. Собрать APK

```bash
npm i -g eas-cli
eas login
npm run build:rustore
```

Профиль `rustore` в `eas.json` собирает подписанный APK и сам увеличивает `versionCode`. Ключ подписи хранится в EAS: им же подписывай все следующие версии, иначе RuStore не примет обновление. Ссылка на APK появится в конце сборки.

## 2. Карточка приложения

Консоль: https://console.rustore.ru → «Приложения» → «Создать».

- **Пакет:** `com.jssensei.app`
- **Иконка:** `docs/store/icon-512.png`
- **Скриншоты** (1080×1920): `docs/store/screenshots/1-home.png` … `8-profile.png`
- **Категория:** Образование
- **Возрастной рейтинг:** 0+ (нет рекламы, покупок и пользовательского контента, кроме ника в рейтинге)

Тексты в стиле приложения: со строчной буквы, без длинных тире и без точки в конце абзаца. Лимиты RuStore на момент написания: название до 50 символов, краткое описание до 80, полное до 4000, «что нового» до 500. Длины ниже посчитаны.

**Название** (28 симв.)

```text
JS Sensei: JavaScript с нуля
```

**Краткое описание** (69 симв.)

```text
учи JavaScript по 5 минут в день: теория, задачи на коде и повторения
```

**Полное описание** (1489 симв.)

```text
короткие уроки по JavaScript, которые можно проходить в метро или в очереди. в каждом уроке пара абзацев теории с примером и 5 заданий по коду

задания такие:
• что выведет код
• верно или нет
• заполни пропуск
• расставь строки по порядку
• найди строку с ошибкой

после ответа видно, почему он правильный или нет. код из задания можно запустить прямо в приложении и посмотреть, что он выводит на самом деле

внутри 210 уроков и больше 1000 заданий в 14 разделах:
• переменные, типы и операторы
• условия, циклы и функции
• массивы, объекты, Set и Map
• деструктуризация, spread, ?. и ??
• строки и регулярные выражения
• map, filter, reduce и чистые функции
• итераторы и генераторы
• JSON, числа и Math
• замыкания, this, прототипы и классы
• Event Loop, Promise и async/await
• debounce, throttle и мемоизация
• ошибки и отладка
• вопросы с собеседований
• алгоритмы на массивах и строках

пройденные вопросы потом возвращаются в тренировку через 2, 4, 8, 16 и 32 дня. те, где ты ошибся, приходят первыми

если основы уже знаешь, выбери уровень при первом запуске или пройди тест на 5 минут, и знакомые разделы засчитаются

ещё есть задача дня (одна для всех), цель на день, стрик, достижения и недельный рейтинг, если захочешь в нём участвовать. напоминание приходит раз в день и только если ты сегодня ещё не занимался

нашёл ошибку в задании? под ответом есть кнопка, чтобы написать нам

без рекламы, покупок и регистрации. уроки работают без интернета, он нужен только для рейтинга
```
