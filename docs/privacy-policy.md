# Политика конфиденциальности JS Sensei

Последнее обновление: ноябрь 2026

## 1. Общие положения

JS Sensei («Приложение») не продаёт персональные данные и не использует их для рекламы. Почти все данные хранятся только на вашем устройстве.

## 2. Данные на устройстве

Приложение сохраняет на вашем устройстве:

• Прогресс обучения (пройденные уроки, звёзды, XP, стрик)
• Историю ответов для интервальных повторений
• Настройки (цель дня, напоминания, звук)

Эти данные не покидают устройство.

## 3. Рейтинг (по желанию)

Если вы выбираете ник и присоединяетесь к рейтингу, на сервер (Google Firebase) отправляются: ник, случайный идентификатор игрока, XP, уровень и длина стрика. Эти данные видят другие участники рейтинга. Без ника ничего не отправляется. Выйти из рейтинга можно в настройках; для удаления записи напишите на адрес ниже.

## 4. Уведомления

Напоминания о занятиях планируются локально на устройстве и не требуют сервера. Их можно отключить в настройках приложения или телефона.

## 5. Аналитика и реклама

Приложение не использует сторонние сервисы аналитики, рекламные сети или инструменты отслеживания.

## 6. Права пользователя

Вы можете сбросить прогресс в настройках или удалить все локальные данные, удалив приложение. По запросу мы удалим вашу запись из рейтинга.

## 7. Дети

Приложение не предназначено для детей до 13 лет и не собирает сознательно данные несовершеннолетних.

## 8. Изменения политики

В случае изменения политики обновлённая версия будет опубликована в приложении с новой датой.
